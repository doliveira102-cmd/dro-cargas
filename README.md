# DRO Cargas

Sistema operacional de controle de cargas, agendamentos, manifestos, clientes, motoristas, veículos, anúncios, rascunhos, backup e restauração.

## Como publicar

Envie estes arquivos para o repositório GitHub:

- `index.html`
- `README.md`
- `.nojekyll`

Depois conecte o repositório na Vercel ou GitHub Pages.
